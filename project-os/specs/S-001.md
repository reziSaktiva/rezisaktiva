## Decision

ADR-049 is the accepted decision for this program.

## Goal

Reshape rezisaktiva's agent ecosystem into an English `project-os/` document system with specs, tickets, a short context layer, English process instructions, and preserved product history.

## Scope

- Rename the former Project Manager folder to `project-os/`.
- Replace the old task queue model with `AVAILABLE_TICKETS.md` plus `tickets/`.
- Add `specs/` for multi-session programs and keep this program as `S-001`.
- Add a short `context/` pointer layer.
- Translate Project OS docs, process skills, always-on rules, product-discovery docs, ADRs, ticket archives, and developer-facing source comments to English.
- Keep IDs, dates, statuses, decisions, links, and product meaning intact during translation.

## Out of Scope

- Changing public site product behavior.
- Translating bilingual locale copy in `content/`.
- Reviving or updating `design-mockups/` as a production design target.
- Moving project skills out of `.cursor/skills/`.
- Creating `.claude/`.
- Translating `COMPLETE_TASK.md` beyond the freeze banner.
