### Dark / light — how

Product contract = ADR-021. Only **mechanism** changes.

**Do**

1. Read cookie `rz-theme` in `app/layout.tsx` (already there). Set on `<html>`: `style={{ colorScheme: initialMode }}`, `<meta name="color-scheme" content={initialMode} />`. Class `dark` **must not** via React `className` on `<html>` (overwrites Lenis / `ct-lock` / `qi-lock` / `ps-lock` / `page-vt-lock`). Use `classList.toggle("dark")` in `beforeInteractive` script + `ThemeModeProvider`.
2. Tailwind v4: `@custom-variant dark (&:is(.dark *));` so `dark:` follows **class**, not OS. Do not rely on `prefers-color-scheme` as token source.
3. Tokens: `:root { --background: … }` light; `.dark { --background: … }` dark. Map values from `lib/astryx-theme.ts` (light/dark pairs below). `@theme inline { --color-background: var(--background); … }` so `bg-background` / `text-foreground` work.
4. Keep `lib/theme-mode.ts` + `useSyncExternalStore` + write cookie+localStorage. `ThemeModeProvider` **stops** rendering Astryx `<Theme>`; context + sync `document.documentElement.classList` / `colorScheme` on toggle only.
5. `beforeInteractive` script: `classList.toggle("dark")` + `data-theme` + `color-scheme` from **cookie** (not no-op when cookie exists). Self-healing localStorage only if cookie missing. Do not `setAttribute("class")`. Do not read localStorage if cookie exists (anti-flash 2026-08-16).
6. Nav chip: keep `useChipColorVars()` (React mode hex). No `light-dark()`.
7. Contact `.ct-panel`: stay dark-ink **both themes**.
8. Scrollbar T-025.9: track/thumb follow new tokens, light and dark.

**Do not**

- Default dark, or auto-follow OS
- `next-themes` as source of truth (unless proven equivalent cookie SSR without flash — default no)
- Raw `dark:` for brand palette that already has variables (`bg-zinc-950 dark:bg-white` forbidden)
- Remove anti-flash `cookies()` “for pure SSG” without new ADR
