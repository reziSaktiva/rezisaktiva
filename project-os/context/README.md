# Context

Short pointer layer for agents and contributors working on rezisaktiva.

This folder is an index, not a second copy of the product or operating baseline. Use it to find the right Source of Truth, then read the referenced document before making decisions or changes.

## Index

- [`ctx-project.md`](ctx-project.md) — project operating system, status, tickets, ADRs, and workflow.
- [`ctx-product.md`](ctx-product.md) — business, product, user, and validation baseline pointers.
- [`ctx-architecture.md`](ctx-architecture.md) — architecture and major technical decision pointers.
- [`ctx-development.md`](ctx-development.md) — engineering workflow, implementation rules, and code conventions.
- [`ctx-design.md`](ctx-design.md) — UX, visual identity, production design source, and motion pointers.

## Source Rules

- Project operations live in [`../`](../).
- Product baselines live in [`../../product-discovery/`](../../product-discovery/).
- Decisions live in [`../DECISIONS.md`](../DECISIONS.md) and [`../decisions/`](../decisions/).
- Current status lives in [`../PROJECT_STATE.md`](../PROJECT_STATE.md), not in this folder.
- Open work lives in [`../AVAILABLE_TICKETS.md`](../AVAILABLE_TICKETS.md); ticket history lives in [`../tickets/`](../tickets/).
