# Wave retro

Last step of `wave-work`. Suggestions only. Do not edit rules, skills, or tickets from this step. Boss Rezi decides what to act on.

## How to compile it

1. Include only events that cost time or tokens, or nearly went wrong. No event, no item.
2. Write each as a suggestion: what to change, which file, and the evidence.
3. At most 5 items. Put a wrong result or an unauthorized action first, then wasted time, then convenience.
4. If a suggestion already lives in a rule or skill, point to it. Do not repeat a lesson already in `SKILL.md`.

## Categories

| Category | Question |
| -------- | -------- |
| Navigation | Which document was opened too often or misread? |
| Checks | Which mistake showed up late and a command could have caught sooner? |
| Tool economy | Which read, command, or model cost more than the work needed? |
| Instructions | Which instruction was read and then ignored or contradicted? |
| Access | What was out of reach: permission, network, or a missing tool? |

## Output

```markdown
# Retro <wave name> · <date>

1. [<category>] <suggestion> · Evidence: <event> · Severity: high | medium | low
```
